ZXing-WASM reader 3.1.5

The local `reader.js` and `zxing_reader.wasm` files are from the open-source
`zxing-wasm` npm package, reader-only build. They are loaded when a user opens
the camera scanner; barcode images are decoded in the browser without a CDN or
a paid service.

Source: https://github.com/Sec-ant/zxing-wasm
