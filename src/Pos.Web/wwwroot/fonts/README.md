# VaultFlow web fonts

Latin variable WOFF2 subsets of DM Sans and Manrope, downloaded from Google Fonts on 2026-10-08. Serve these from the same origin with `font-display: swap` so the main stylesheet never waits for an external font stylesheet.

Sources:
- DM Sans: https://fonts.gstatic.com/s/dmsans/v17/rP2Yp2ywxg089UriI5-g4vlH9VoD8Cmcqbu0-K4.woff2
- Manrope: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Licenses: https://github.com/google/fonts/tree/main/ofl/dmsans and https://github.com/google/fonts/tree/main/ofl/manrope

Both fonts use the SIL Open Font License 1.1. The original license texts are included in this folder. Characters outside these subsets use the browser's fallback fonts.
